# 당신의 자격은 무엇입니까? — 2099 NEW SEOUL v3

홍길동전의 서얼 차별과 권력 부패 문제를 2099년 사회 등급제에 연결한 QR 웹게임입니다.

## 이번 업데이트
- 시작 버튼을 누르면 A/B/D등급 중 하나가 무작위 배정되고, 기기 브라우저에 저장됩니다.
- 등급별 첫 장면과 공통 사건의 일부 대사가 달라집니다.
- 시민 등급 산정 규칙과 내부 거래 기록/알고리즘 로그를 실제로 조사하고 수집합니다.
- 증거, 연대, 감시 위험이 누적되며 최종 엔딩의 결과가 달라집니다.
- 순응, 폭로, 변화의 세 결말과 1년 후(2100년) 뉴스로 사회 변화가 표시됩니다.
- 네온·홀로그램 UI, 감시 알림, 전자 신호 효과음과 긴장감 있는 오리지널 SF 배경음악을 넣었습니다.
- 모바일/아이패드/PC 반응형, 저장, 공유, 자료 보관함을 지원합니다.

## 기존 GitHub Pages에 업데이트하기
1. 이 ZIP 파일을 압축을 풉니다.
2. GitHub 저장소 `kongbinnim-beep/honggildong-game`를 엽니다.
3. 저장소 최상위에 `index.html`, `styles.css`, `game.js`를 새 버전으로 바꾸고, `assets` 폴더의 이미지와 음원을 함께 업로드합니다. **ZIP 파일 자체는 올리지 마세요.**
4. `Commit changes`를 누릅니다.
5. `Settings` → `Pages`에서 배포 상태가 완료됐는지 확인합니다.
6. `https://kongbinnim-beep.github.io/honggildong-game/`에서 새로고침합니다. 캐시 때문에 이전 버전이 보이면 주소 뒤에 `?v=3`을 붙입니다.

주소가 같으므로 기존 QR 코드의 대상 주소도 계속 사용할 수 있습니다. 단, 공개 게임은 GitHub에 업데이트해야 바뀝니다.

## 플레이 및 기술 참고
- 첫 접속 등급 배정은 브라우저별로 무작위이며, 1:1:1 비율을 보장하지는 않습니다.
- 진행 상태는 `localStorage`에 저장되어 새로고침 시 복원됩니다.
- '새 시민으로 시작'을 누르면 저장된 상태가 지워지고 새로운 등급이 배정됩니다.
- 모바일 브라우저는 자동 음악 재생을 제한하므로 상단 '음악 켜기' 버튼을 눌러야 배경음악이 재생됩니다.
- `game.js`에서 서사, 등급, 문서, 엔딩 및 수치 조건을 조정할 수 있습니다.
- CDN·API·회원가입 없이 정적 호스팅에서 실행됩니다. 외부 Google Fonts가 차단되어도 대체 글꼴로 표시됩니다.
