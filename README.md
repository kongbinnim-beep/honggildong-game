# 당신의 자격은 무엇입니까? — D등급 고정 개편판

## 원작 홍길동전과 연결
모든 플레이어는 **D등급 시민**으로 시작합니다. 뛰어난 능력이 있어도 출신 가정 때문에 진학과 취업 기회를 제한받는 상황을 경험합니다. 홍길동이 서얼 신분으로 차별받는 장면을 미래의 등급제 사회에 투영했습니다.

## 유지된 게임 기능
- 모두 D등급으로 출발하지만 선택지는 플레이어가 직접 선택합니다.
- 등급 산정 규칙, 권력층 비밀 거래 기록, 차별 알고리즘을 직접 조사하고 수집합니다.
- 증거/시민 연대/감시 위험에 따라 엔딩의 1년 후 상황이 달라집니다.
- 순응/폭로/변화의 세 결말, 2100년 뉴스, 미래형 일러스트/배경음악/효과음, 모바일 대응, 자동 저장 및 공유 기능을 유지했습니다.
- '다시 시작'을 눌러도 **D등급 고정**이며 이야기 속 선택을 새롭게 시도할 수 있습니다.

## GitHub Pages 갱신 방법
1. ZIP 압축을 풀고 **ZIP 자체가 아니라** `index.html`, `game.js`, `styles.css`, `assets` 폴더를 저장소 최상위에 업로드합니다.
2. 기존 파일 이름을 유지하고 GitHub에서 변경 사항을 커밋합니다.
3. 기존 URL `https://kongbinnim-beep.github.io/honggildong-game/`에서 플레이할 수 있습니다.
4. 변경 사항이 바로 보이지 않으면 `?v=4-fixed-d`를 주소 뒤에 붙이거나 강력 새로고침하세요.

## 기술적 안내
이전 랜덤 등급 저장과 혼동하지 않도록 새로운 로컬 저장 키를 사용합니다. 첫 접속은 D로 고정되며, 기존 v3 플레이 기록은 이어서 불러오지 않습니다. 배경음악은 모바일에서 사용자 터치 이후 재생할 수 있습니다. 별도 서버는 필요 없는 정적 웹게임입니다.
