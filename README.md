# 홍길동전: 지워진 이름들 — 감성 강화판

포함 내용:
- 배경 음악 on/off
- 장면 일러스트 5장
- 가독성 강화된 스토리 UI
- 모바일 / 아이패드 / PC 대응

## GitHub Pages에 다시 올리는 방법
1. 이 ZIP을 압축 해제합니다.
2. GitHub 저장소 `honggildong-game`에 들어갑니다.
3. 기존 파일을 삭제하거나 덮어쓰고, 이 폴더 안의 `index.html`, `styles.css`, `game.js`, `assets` 폴더를 업로드합니다.
4. `Commit changes`를 누릅니다.
5. 몇 분 뒤 기존 주소에서 자동 반영됩니다.

주소는 그대로 유지되고 QR 코드도 그대로 쓸 수 있습니다.
